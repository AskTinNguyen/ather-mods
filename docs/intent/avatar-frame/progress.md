Chromium paints a frame's page opaque when that page's colour scheme differs from the iframe element's (the app's): the page root has none (normal = light), so in the dark theme the page is white. The svg's own `style="color-scheme: light dark"` names the svg element, not the page root, so it never helped. Fix: `avatarSvg` starts with `FRAME_SCHEME` = `<style>:root{color-scheme:light dark;background:transparent}</style>`, which in the frame page sets the html root to `light dark` (it then takes the app's scheme), and in a still image names the svg root and changes nothing.
