How an answer reaches the repository

Your answer is kept on this page. A Claude session running the desk skill records it in the intent's findings the intent skill's way, one pull request per repository, and marks it Recorded here. Once that pull request is merged, the next read of the desk shows it settled. You can change an answer until it is recorded.
